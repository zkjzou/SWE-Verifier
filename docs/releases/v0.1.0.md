# v0.1.0 preview

The package is currently `0.1.0.dev0`.

Included:

- Four verifier variants with independent gate and selector roles.
- Trajectory-level, all-step, and gate-only strategies.
- 18 recipes and 32 packaged prompts.
- Resumable data construction and canonical training exports.
- External SWE-bench grading report import.
- Four-H200 training scripts for Score Only, Joint Rubric, and Two-Stage Rubric, including checkpoint resume.

Public model/data access and validation of full GPU training runs are pending. Paper-result reproduction is not yet established. Artifact revisions and access requirements are listed in the [model card](../model-card.md), [dataset card](../dataset-card.md), and [release manifest](../../release-manifest.json).
